Appendix: determinant identity

\[ \Gamma_{\!\text{post}}(S) = \left( \Gamma_{\!\text{prior}}^{-1} + F_S^{*}\, \Gamma_{\!\text{noise},S}^{-1}\, F_S \right)^{-1} \]
\[ \det \Gamma_{\!\text{post}}(S) = \det \Gamma_{\!\text{prior}}\; \frac{\det \Gamma_{\!\text{noise},S}}{\det K_S} \]
\[ f(S) = \frac{1}{2} \left[ \log\det K_S - \log\det\, (\Gamma_{\!\text{noise}})_S \right] \]

No assumption of time invariance is needed for this identity.

Appendix: diminishing returns

\[ \Delta_s(S) = I(m;\, d_s \mid d_S) = H(d_s \mid d_S) - H(\eta_s) \]
\[ \Delta_s(A) \ge \Delta_s(B) \quad \text{for} \quad A \subseteq B,\; s \notin B \]

Conditioning on more sensors reduces the remaining information.

Noise entropy is unchanged for independent sensor noise.

\[ f(S_B) \ge \left[ 1 - (1 - 1/B)^B \right] f(S^*) \ge (1 - 1/e)\, f(S^*) \]

Appendix: a posteriori optimality bound

Sort the remaining marginal gains at each visited set \(S_t\).

\[ U_t = f(S_t) + \sum_{j=1}^{B} \Delta_{(j)}(S_t), \qquad U = \min_t U_t \]
\[ f(S^*) \le f(S_t \cup S^*) \le f(S_t) + \sum_{s \in S^* \setminus S_t} \Delta_s(S_t) \le U_t \]
\[ \frac{f(S_B)}{f(S^*)} \ge \frac{f(S_B)}{U} \]

Sum the largest B gains. Use normalized information gain.

Appendix: normalization and objective variants

\[ f(S) = \frac{1}{2} \log\det \overline{K}_S, \qquad f(\varnothing) = 0 \]

\(\overline{K}\) denotes the noise-whitened data covariance.

Normalize by the selected noise covariance before forming ratios.

\[ \widetilde{K} = \Gamma_{\!\text{noise}} + F\, W_m\, \Gamma_{\!\text{prior}}\, W_m^{*}\, F^{*} \]

Parameter weights modify the prior-induced observation covariance.

Noise weights and candidate exclusions provide other design variants.

Appendix: scaling methodology

  • Strong scaling: 8,192 candidate evaluations
  • Weak scaling: 256 candidates per MPI rank
  • Frontier: two GCD ranks per physical GPU
  • Randomized modulo indexing reuses the 600-sensor matrix.

Replicated Cholesky storage grows quadratically with the sensor budget.
