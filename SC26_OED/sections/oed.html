Optimal experimental design (OED)

Given:
Set of candidate sensor locations (e.g., \(N_d = 600\)) and fixed budget of \(B\) sensors
Task:
Select optimal sensor subset \(S\) of size \(|S| \le B\) that provides the maximum information about the uncertain parameters \(m\) (seafloor motion)
Bayesian approach:

Maximize the expected information gain from the prior to the posterior

For the linear-Gaussian case, this is equivalent to the D-optimal design criterion:

\(\displaystyle S_{\text{opt}} \;=\; \underset{S,\;|S|\le B}{\arg\min}\; \log\det\) \(\displaystyle \Big( \underbrace{(\Gamma_{\!\text{post}})_S}_{} \Big)\) \(10^9 \times 10^9\) matrix
must be recomputed from scratch for each \(S\)

Computable D-optimal design

  • Using linear algebra techniques, we can show that
    \[ \textcolor{#f6b93b}{\det}\textcolor{#6aaee8}{\big((\Gamma_{\!\text{post}})_S\big)} \;=\; \dots \;=\; \textcolor{#f6b93b}{\det(\Gamma_{\!\text{prior}})\,\det(\mathbf{K}_S^{-1})\,\det((\Gamma_{\!\text{noise}})_S)} \]

    where \(\mathbf{K} = \Gamma_{\!\text{noise}} + \mathbf{F}\,\Gamma_{\!\text{prior}}\mathbf{F}^*\) is the data-space Hessian

  • D-optimal criterion reduces to maximizing \(\log\det(\mathbf{K}_S)\)

D-optimal design: Greedy algorithm

  • Even in computable form, finding the optimal sensor set is an NP-hard combinatorial optimization problem → use greedy algorithm to find an approximate solution

Greedy algorithm: (find optimal set \(S\) iteratively)

1.
Initialize \(S = \emptyset\)
2.
For \(k = 1\) to \(B\):
Find the sensor \(i^*\) not in \(S\) that maximizes the gain
\[ i^* = \underset{i \,\notin\, S}{\arg\max}\; \big[\, J(S \cup \{i\}) - J(S) \,\big] \quad \text{where} \quad J(S) = \log\det(\mathbf{K}_S) \]
Add the best sensor: \(S \leftarrow S \cup \{i^*\}\)
3.
Return \(S\)

Gain calculation (evaluating \(J(S \cup \{i\})\) for each candidate \(i\)) can be done efficiently via Schur complements + Cholesky updates that avoid re-factorizing \(\mathbf{K}_S\)

  • Independent candidate evaluations provide the parallelism for the GPU algorithm.
