Acoustic–gravity forward model

  • Partial differential equation (PDE) model
    \[ \rho\,\frac{\partial \vec{u}}{\partial t} + \nabla p = 0, \qquad \frac{1}{\kappa}\,\frac{\partial p}{\partial t} + \nabla\cdot\vec{u} = 0 \]
  • Boundary conditions
    • Sea surface (coupling with surface-gravity wave)
      \[ p = \rho g \eta, \qquad \partial\eta/\partial t = \vec{u}\cdot\vec{n} \]
    • Seafloor velocity (boundary source)
      \[ \vec{u}\cdot\vec{n} = \textcolor{#6aaee8}{m} \]
    • Lateral absorbing boundary (outgoing waves)
      \[ \vec{u}\cdot\vec{n} = p/\rho c \]

(Lotto & Dunham, 2015)

  • Initial conditions (homogeneous)
  • Implemented with MFEM using high-order finite elements and RK4 time-stepping
  • PDE defines the parameter-to-observable (p2o) map \(F : m(\vec{x},t) \mapsto d(\vec{x},t)\)

FFTMatvec: fast forward and adjoint actions

Time-shift invariance → discrete p2o map \(\mathbf{F}\) is block-triangular Toeplitz:

  • \(N_m \times N_d\) blocks (spatial param. dim. × num. sensors)
  • Each block is \(N_t \times N_t\) (num. of timesteps)
  • Precompute \(\mathbf{F}\) by solving one adjoint PDE per sensor
  • Block Toeplitz matrix is block-diagonalized by FFT
  • Full high-fidelity physics – no surrogates or reduced-order models
